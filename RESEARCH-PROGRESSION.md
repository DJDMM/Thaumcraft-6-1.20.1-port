# Начальные исследования TC6 в 0.6.0-dev

Эталон — официальный **Thaumcraft 6.1.BETA26**. Требования читаются из его
исходных JSON, сохранённых в `data/thaumcraft/legacy_research`; строки,
отформатированные для книги, не используются для принятия серверных решений.

| Запись | Реализованная последовательность |
| --- | --- |
| FIRSTSTEPS | Получение/использование книги → начало → изготовление магического верстака → изготовление таумометра + одно наблюдение Basics → заключительный текст |
| KNOWLEDGETYPES | Пустая стадия автоматически завершается как связанное открытие FIRSTSTEPS |
| THEORYRESEARCH | После KNOWLEDGETYPES → начало → изготовление набора писца и исследовательского стола → заключительный текст |
| CELESTIALSCANNING | После THEORYRESEARCH → начало → по одному наблюдению Basics, Artifice и Auromancy → небесное сканирование |
| UNLOCKALCHEMY | Завершённые первые шаги → начало → наблюдения Basics + Alchemy по одному → изготовление тигля → изготовление жёлтого нитора |
| BASEALCHEMY | После UNLOCKALCHEMY пустая стадия завершается при открытии |
| ALUMENTUM | После BASEALCHEMY → начало → одно наблюдение Basics → заключительный текст и доступ к рецепту |

Неизвестная запись имеет стадию 0; 1…N обозначают текущую стадию,
N+1 — завершение. Начало не оплачивает требования первой стадии.
Пустая заключительная стадия пропускается при завершении предыдущей,
но её текст показывается в законченной записи. Переход даёт 5 XP;
автоматическое завершение KNOWLEDGETYPES дополнительно даёт 5 XP один раз.
Рецепт таумометра требует FIRSTSTEPS@2, нитора — UNLOCKALCHEMY@3;
это доступ до нужного крафта, поэтому цепи не замыкаются сами на себя.

## Наблюдения, факты и оплата

Каждый новый скан с положительными аспектами начисляет сырые наблюдения
по всем семи исходным категориям. Формула BETA26:
`ceil(sqrt(sum(amount × categoryWeight / 10)))`.
Весы перенесены из ConfigResearch и сверены с оригинальным JAR.
16 сырых единиц дают одно полное наблюдение; остаток сохраняется после оплаты.
Theory хранит 32 единицы на балл; стол начисляет сырые награды по процентам
после завершения сессии. Правила и границы — в [THEORYCRAFTING.md](THEORYCRAFTING.md).

Факт крафта появляется после успешной серверной операции: обычный/магический
крафт, превращение Salis Mundus в верстак или тигель, рецепт тигля,
превращение деревянного стола набором писца и перезаправка набора.
Наличие предмета в инвентаре, `/give`, предпросмотр рецепта или неудачная
операция не заменяют изготовление. Доказательство не расходуется.

Сервер проверяет контекст игрока, родителей, ожидаемую стадию, все факты
и все категории знания до списания. Несовпавшая стадия возвращает STALE;
повторный пакет не оплачивает следующую стадию. Для запроса из книги нужен
Таумономикон в любой руке. Архив не отправляет запросы оплаты.
Парсер имеет поддержку планирования предметного расхода, но выбранные семь
записей не содержат required_item: этот путь не заявляется проверенным для всего TC6.

Подбор vis-кристалла записывает !gotcrystals. Пробуждение после сна выдаёт
однократный журнал Strange Dreams с тремя оригинальными страницами; при полном
инвентаре он выпадает рядом. Начало FIRSTSTEPS также открывает !gotdream,
как исходная связь siblings. Рецепт Salis Mundus и его превращения пока доступны
без проверки сна; конфигурационный обход noSleep ещё не перенесён.

## Сохранения и совместимость

SavedData v2 сохраняет сырые знания, стадии, факты крафта и список уже
оплаченных сканов. В 0.6 добавлены необязательные поля небесной дневной квоты
и временного warp; существующие v2-сохранения читаются без потери прогресса. Старые сохранения 0.2/0.3 сохраняют аспекты, количество
сканов и завершённые PORT-уроки. Старый объект можно заново просканировать
один раз для новых наблюдений, не увеличивая число уникальных сканов;
последующие сканы не начисляют знания, в том числе после перезапуска.

Старые recipe aliases оставляют ранее открытые рецепты доступными, но не
записывают фиктивное завершение исходного исследования. Например, PORT_NITOR
сохраняет доступ к UNLOCKALCHEMY@3 для рецепта, тогда как настоящая стадия
UNLOCKALCHEMY остаётся 0. PORT_START сохраняет доступ к таумометру.

Латунь, жир/кожа и таумий пока используют три оставшихся практических урока
с прежними условиями по сканам и аспектам. Завершённая BASEALCHEMY разрешает
их родительский доступ. Старые стартовые уроки скрыты для нового персонажа;
сервер отклоняет попытку обойти исходную цепь через старый запрос.

## Что этот этап не завершает

148 записей архива и 271 стадия сохранены для справки. Полноценная металлургия,
остальные карточки и помощь стола, небесные наблюдения, остальные исследования,
warp, производство/транспорт эссенции, инфузия и ауромантия ещё нужны.
BASEALCHEMY как запись завершена; все описанные в ней преобразования предметов
ещё не реализованы. Модель нитора пока временная, цветовые варианты отсутствуют.
Старые миры Minecraft 1.12.2 не конвертируются.

Проверки и их границы — [VALIDATION.md](VALIDATION.md).
