# Thaumcraft 6 — Forge 1.20.1

Неофициальный перенос **Thaumcraft 6.1.BETA26** с Minecraft 1.12.2 на **Minecraft 1.20.1 / Forge 47.4.10 / Java 17**. Текущая версия: **0.17.0-dev**. Проект в разработке: полный мод ещё не перенесён.

## Установка

1. Создайте профиль Minecraft **1.20.1** с Forge **47.4.10** и Java **17**.
2. Положите в `mods` два файла: `thaumcraft-1.20.1-0.17.0-dev.jar` и `TerraBlender-forge-1.20.1-3.0.1.10.jar`.
3. Запустите профиль и создайте новый мир. Готовый `mods.zip` содержит оба JAR.

Baubles для 1.12.2 не требуется. Перенос сохранений Minecraft 1.12.2 не реализован.
Клиент и сервер должны использовать одну версию мода: протокол исследований — 4,
добавлено серверное подтверждение прочтения страниц. Сохранённые знания порта совместимы; ранее
установленные клапаны/односторонние трубы получают рабочую логику при загрузке чанка.

## Начало игры

1. Добудьте первичные кристаллы. После подбора кристалла поспите: получите «Странные сны».
2. Из трёх разных кристаллов, кремня, миски и красной пыли изготовьте Salis Mundus. Кремень и миска возвращаются.
3. Примените Salis Mundus к книжной полке для Таумономикона, затем к верстаку для магического верстака. Следуйте стадиям «Первых шагов» в книге.
4. После первой стадии изготовьте таумометр: стеклянная панель в центре, четыре золотых слитка крестом, по одному из шести первичных кристаллов в специальных слотах; цена без скидки — 20 vis.
5. ПКМ таумометром сканирует цель, Shift+ПКМ — другую руку. Затем развивайте начальную алхимию через книгу. Тигель создаётся Salis Mundus из пустого котла.

После открытия ауромантии начните BASEAUROMANCY: изготовьте малый фокус в тигле,
затем стол обработки фокусов и испытайте огненный урон на второй стадии.
Это открывает исходную цепочку Recharge Pedestal → Traveller Boots → Elemental
Tools / Fortress с её требованиями знаний, статистики, сканов и изготовления.
Завершённое FOCUSELEMENTAL открывает Воздух, Холод и Землю. После первой оплаты
FOCUSPROJECTILE, на стадии `@2`, доступны обычные снаряды; отскок и поиск целей
требуют полного завершения этого исследования. Создание и применение фокусов
описаны в [AUROMANCY.md](AUROMANCY.md).

Подробнее: [RESEARCH-PROGRESSION.md](RESEARCH-PROGRESSION.md), [THEORYCRAFTING.md](THEORYCRAFTING.md), [CELESTIALSCANNING.md](CELESTIALSCANNING.md).

## Сборка и запуск

Установите JDK 17 и укажите его в `JAVA_HOME`. Gradle Wrapper включён в репозиторий.

Windows PowerShell:

```powershell
.\gradlew.bat build
```

Обычный интерактивный запуск — `.\gradlew.bat runClient`: окно появится на текущем рабочем столе и может забрать фокус. Для фоновых проверок на Windows используйте изолированный скрипт ниже.

Linux/macOS:

```sh
chmod +x gradlew
./gradlew build
./gradlew runClient
```

Результат: `build/libs/thaumcraft-1.20.1-0.17.0-dev.jar`. Для первой сборки нужен интернет: Gradle загружает Forge и TerraBlender.

## Проверка

```powershell
python scripts/validate_resources.py
.\gradlew.bat runGameTestServer
.\scripts\run_client_smoke_isolated.ps1 -SmokeTest Auromancy
.\scripts\run_client_smoke_isolated.ps1 -SmokeTest Infusion
.\scripts\run_client_smoke_isolated.ps1 -SmokeTest ThaumonomiconComplete
.\scripts\run_client_smoke_isolated.ps1 -SmokeTest EssentiaProduction
.\scripts\run_theory_smoke_isolated.ps1
```

Серверные GameTests работают в `run/gametest-server`; перед повторным полным прогоном сохраните прежний QA-мир `world` под другим именем. Остатки предметов вне малых шаблонов могут искажать подсчёт добычи. Игровые сохранения для этого не используются.

Профиль `Auromancy` использует `-PauromancySmokeTest` и отдельный
`run/auromancy-smoke` для стола, выбора фокуса, стихий и движущихся снарядов.
Профиль `ThaumonomiconComplete` проверяет все страницы книги в отдельном
`run/thaumonomicon-complete-smoke`. На Windows
`run_client_smoke_isolated.ps1 -SmokeTest EssentiaProduction` готовит `-PessentiaProductionSmokeTest`; профиль `TheoryComplete` и совместимый `run_theory_smoke_isolated.ps1` проверяют стол исследований. Скрипт затем запускает итоговую JVM на отдельном скрытом рабочем столе Win32, без переключения стола и активации окна. Он отключает звук, ограничивает FPS до 30 и сохраняет PNG/логи; параметр `-JavaHome` задаёт путь к Java 17, `-PrepareOnly` выполняет только подготовку. Это не стол Task View: взаимодействие выполняет тестовый сценарий, а CPU/GPU остаются общими. [Устройство запуска](scripts/windows-desktop/README.md).

Производство/трубы проверяются в `run/essentia-production-smoke`, полный стол — в `run/theory-complete-smoke`, ранняя прогрессия — в `run/early-survival-smoke`, оборудование — в `run/equipment-smoke`. Эти сценарии сохраняют реальные скриншоты и завершают только свой тестовый клиент. Результаты выполненных проверок и их границы — [VALIDATION.md](VALIDATION.md).

Итог0.17 — **441/441 серверных тестов и15/15 клиентских сцен**. Все итоговые
PNG просмотрены; проверены реальные создание/установка/полёт/попадание,
однократная оплата и сохранения. Fixtures и границы доказательства,
артефакты и SHA-256 — в [VALIDATION.md](VALIDATION.md).

Раннюю прогрессию и оборудование включают параметры `-PearlySurvivalSmokeTest` и `-PequipmentSmokeTest`. Прямой `runClient` с любым параметром открывает окно на текущем рабочем столе; готовый изолированный скрипт поддерживает начальную ауромантию, наполнение, полный Таумономикон, стол исследований и производство/трубы эссенции.

Другие отдельные клиентские сценарии: `-PthaumometerSmokeTest`, `-PessentiaSmokeTest`, `-PcatalogSmokeTest`, `-PtheorySmokeTest`, `-PbiomeSmokeTest`. Обычный `runClient` не включает автоматические сценарии. `runClient -PgameplayTest` добавляет в чат команды проверки биомов; перед выполнением нужны Enter и разрешённые читы. Команды и особенности Eerie/Outer Lands — [BIOMES.md](BIOMES.md).

## Структура и оставшаяся работа

- `src/main/java/thaumcraft` — серверные системы, API, предметы и клиент.
- `src/main/resources/assets/thaumcraft` — модели, текстуры, звуки и локализации.
- `src/main/resources/data/thaumcraft` — рецепты, теги, аспекты и генерация мира.
- `docs/tc6` — закреплённые источники, аудит байткода и спецификации TC6.
- `scripts/validate_resources.py` — проверка ресурсов и переводов.

Ещё нужны: остальные исследования и их prerequisites, остальные 14 доставок/эффектов/модификаторов из 21 узла фокусов, аксессуары и их слоты, зеркальный транспорт и остальные воздушные потребители эссенции, поздние исследования плавилен/мехов, большая часть устройств, големы и AI существ, полный набор событий warp, разломы и заражение. Некоторые способности инструментов используют современные теги и частицы вместо старого Forge/FX API; эти адаптации указаны в [EQUIPMENT.md](EQUIPMENT.md). Получение раннего оборудования реализовано в 0.11; с 0.16 открыты исходные пути к Traveller Boots, Elemental tools и Fortress, но полный мод и позднее survival-прохождение ещё не завершены. Применимость устройства как помощника стола сама по себе не завершает его остальную механику.

Наполнение проверяется в `run/infusion-smoke`; `-SmokeTest Infusion` использует отдельный скрытый рабочий стол и реальные взаимодействия алтаря. Работают семь узлов ROOT/TOUCH/PROJECTILE/FIRE/AIR/FROST/EARTH, обработчики устройств и вис-резонатор; 47 из 56 рецептов наполнения сохраняют недоступные поздние research paths. Разломы, заражение и исходная FX-система ещё не завершены.

Дорожная карта — [PORTING.md](PORTING.md). Документы отдельных систем: [AUROMANCY.md](AUROMANCY.md), [INFUSION.md](INFUSION.md), [THAUMONOMICON.md](THAUMONOMICON.md), [THAUMOMETER.md](THAUMOMETER.md), [ESSENTIA.md](ESSENTIA.md), [BIOMES.md](BIOMES.md), [VISUAL-CATALOG.md](VISUAL-CATALOG.md).

`.gitignore` исключает миры, логи, кэши, результаты сборки и большие материалы автоматических проверок. Эти файлы остаются локально, но не попадают в историю Git.
