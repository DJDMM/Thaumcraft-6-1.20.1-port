# План полного переноса Thaumcraft 6

Цель проекта: Minecraft 1.20.1, Forge 47.4.10, Java 17. Срез **0.20** прошёл
финальный серверный прогон 603/603, скрытый клиентский 22/22 и итоговую
сборку/проверку ресурсов. Подтверждённый QA 0.19 сохранён отдельно как история.
Эталон: Thaumcraft 6.1.BETA26 для Minecraft 1.12.2. Проверенные руководства,
ресурсы, описания механик и ограничения источников — в [docs/tc6/README.md](docs/tc6/README.md).
Upstream: `TheDarkTower314/Thaumcraft-6-Source-Code`, commit
`954022bb777b7546281fb36df8522f0ba6b43f81`.

Полный перенос остаётся в работе. Наличие предмета, текстуры или страницы
исследования не означает готовность связанной игровой механики.

## Порядок следующей работы

Пользователь изменил очередность: сначала полный визуальный каталог 0.8,
затем механики представленных предметов и существ. Каталог проверяется отдельно
и не помечает исходные исследования реализованными. Далее порядок механик:

1. Интерфейс и справка Таумономикона завершены в 0.14. Продолжать игровые
   механики его оставшихся записей; наличие схемы не означает готовность устройства.
2. Проверить длительной игровой сессией путь выживания: кристаллы → Salis Mundus → книга →
   магический верстак → таумометр → знания → тигель → таумий. Эти связи реализованы;
   тесты проверяют отдельные игровые операции, полное прохождение человеком ещё не подтверждено.
3. Продолжить исходную исследовательскую систему: поздние записи, точные события
   и предметные требования. Зарегистрированные карточки и помощь стола завершены в 0.12.
   Базовая модель стадий, сон/книга и начисление наблюдений реализованы в 0.4,
   сессии теорий и базовые карточки — в 0.5; границы описаны в THEORYCRAFTING.md.
4. Все 21 типа узлов, ветвления и изготовление Advanced/Greater реализованы
   в 0.19. Продолжать проверку их сочетаний и исходных мировых prerequisites;
   текущая система и адаптации описаны в AUROMANCY.md.
5. Продолжить устройства, эссенцию и големов: поздние исследования,
   остальные воздушные потребители/автоматизация, печати и задания.
   Производство, банки и шесть труб реализованы в 0.13, алтарь и воздушное
   извлечение для наполнения — в 0.15. Центрифуга подключена в 0.19 как первый
   следующий механизм. Срез 0.20 добавляет ingredient paths BASEARTIFICE/BASEALCHEMY,
   прогрессию таумиевой плавильни/Thaumatorium и INFUSIONSTABLE. Golemancy остаётся
   реальным ограничением mind_clockwork для Brain Box, не этих механизмов/резонатора.
   Наполнение сохраняет 45 поздних gates.
6. Перенести существ, заражение, разломы и оставшийся мир.
7. Проверить обычный клиент/сервер, мультiplayer, сохранения, ресурспаки,
   рецепты и производительность на длительных игровых сессиях.

## Правила интеграции

- Общие данные и открытие исследований проверяет сервер.
- Блоки и предметы регистрируются через DeferredRegister.
- ID вариантов 1.12.2 преобразуются в отдельные современные ID; автоматический
  перенос сохранений пока не заявляется.
- Новые игровые механики проверяются GameTests; GUI дополнительно проверяется
  в клиенте. Список проверок и ограничения — в VALIDATION.md.
- Исторический срез 0.19 проверен собственными финальными build/resource и server/client
  прогонами; статус предыдущих версий не используется как их подтверждение.
- Исторический `validation/focus-019-gametest8.log` завершил **577/577**
  обязательных серверных тестов и BUILD SUCCESSFUL, включая Mine
  callback-removal guard. Финальные build/resource проверки также прошли.
- Auromancy `full-019-client8` прошёл **33/33** сцены и сохранил отдельный
  Bolt кадр; EssentiaProduction `centrifuge-019-client2` прошёл **12/12**.
  Обе JVM exit 0, input desktop Default до/после; все **46** снимков
  просмотрены. Для маленькой Mine подтверждены armed state/resources/pulse
  и renderer binding; подробное совпадение mesh не установлено. Native FX
  остаются адаптацией. Полный QA и границы — [VALIDATION.md](VALIDATION.md),
  [отчёт 0.19](validation/artifact-report-0.19.json).
- Финальный 0.20 server run `automation-020-gametest5` завершил **603/603**
  обязательных GameTests и BUILD SUCCESSFUL после book fix. Клиент
  `thaumatorium-020-client5` прошёл **22/22**, JVM exit 0, input desktop
  Default до/после, 16 owned windows; 1084 baked states и 17 рабочих блоков.
  Настоящие Salis/menu C2S, оплата coal/dust, typed transport и выход в сундук
  проверены. Research, начальная эссенция и Brain Box — явно заданные fixtures.
  `build-0.20-final.log` содержит BUILD SUCCESSFUL, проверены 2783 JSON и
  3542 ресурсных файла. Доказательства и границы —
  [VALIDATION.md](VALIDATION.md), [отчёт 0.20](validation/artifact-report-0.20.json).
- Исходные материалы не переобъявляются свободно лицензированными.
